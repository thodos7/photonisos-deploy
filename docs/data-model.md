# Μοντέλο δεδομένων

## Τύπος περιεχομένου και ταξινομία

| Στοιχείο | Όνομα | Σημείωση |
|----------|-------|----------|
| Custom Post Type | `photo` | Κάθε φωτογραφία. Υποστηρίζει τίτλο, κύριο κείμενο, Featured Image και αναθεωρήσεις. Έχει δικά του δικαιώματα (`photo`/`photos`). |
| Ταξινομία | `topothesia` | Τοποθεσία, 97 όροι (οικισμοί της Σάμου). Μόνο ο διαχειριστής προσθέτει ή αλλάζει όρους. |

## Πεδία τεκμηρίωσης (ACF)

| Πεδίο | Όνομα | Τύπος |
|-------|-------|-------|
| Περιγραφή | `perigrafi` | Text Area |
| Τοποθεσία | `topothesia` | Taxonomy (επιλογή μίας τιμής) |
| Χρονολογία | `xronologia` | Number |
| Εικονιζόμενα πρόσωπα | `eikonizomena_prosopa` | Text |
| Θεματική κατηγορία | `thematiki_katigoria` | Select (48 επιλογές) |
| Πηγή ή ιδιοκτήτης | `pigi__idioktitis` | Text (διπλή κάτω παύλα) |
| Τύπος φωτογραφίας | `typos_photografias` | Select |
| Κατάσταση τεκμηρίωσης | `katastasi_tekmiriosis` | Select |
| Δικαιώματα και άδεια χρήσης | `dikaiomata_adeia_xrisis` | Text Area |

Τα ονόματα των πεδίων πρέπει να μένουν αμετάβλητα, γιατί τα χρησιμοποιεί ο κώδικας της αναζήτησης και των εξαγωγών.

## Παράμετροι αναζήτησης (GET)

| Παράμετρος | Τι είναι | Ερώτημα WP_Query |
|------------|----------|------------------|
| `ps_q` | Λέξη-κλειδί | `s` |
| `ps_loc` | **ID** του όρου τοποθεσίας | `tax_query` (`term_id`) |
| `ps_theme` | Τιμή θεματικής | `meta_query`, σύγκριση `=` |
| `ps_year_from`, `ps_year_to` | Εύρος χρονολογίας (1900–2026) | `meta_query`, `BETWEEN`, `NUMERIC`, μόνο αν στενέψει ο slider |

## Ρόλοι

| Επίπεδο | Ρόλος | Δικαιώματα |
|---------|-------|------------|
| Επισκέπτης | (χωρίς λογαριασμό) | Αναζήτηση, συλλογές, προβολή τεκμηρίου |
| Τεκμηριωτής | `documentalist` | Εισαγωγή και επεξεργασία φωτογραφιών, ανέβασμα εικόνων |
| Διαχειριστής | `administrator` | Όλα (με ταυτοποίηση δύο παραγόντων) |

## Εξαγωγές

- **Dublin Core XML** (μενού Εργαλεία): `dc:identifier`, `dc:title`, `dc:description`, `dc:date`, `dc:spatial`, `dc:source`, `dc:type`, `dc:format`.
- **CSV** (`/wp-admin/index.php?photo_export=1`): 12 στήλες, UTF-8 με BOM.
